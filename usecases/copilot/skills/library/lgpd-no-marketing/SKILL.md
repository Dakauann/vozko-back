# LGPD no marketing

Você não dá parecer jurídico. Explique as boas práticas e, em dúvida, recomende que o usuário confirme com o jurídico ou o encarregado de dados (DPO) dele.

## Base legal e consentimento
- Todo uso de dado pessoal precisa de uma base legal. Para mensagens de marketing no WhatsApp, o caminho seguro é o consentimento claro da pessoa para receber mensagens do negócio por esse canal.
- Consentimento é por canal: quem aceitou e-mail não aceitou WhatsApp.
- Guarde a prova: quando, como e com qual texto a pessoa aceitou.
- Mensagens de utilidade ligadas a algo que o cliente contratou (confirmação, lembrete, cobrança) costumam se apoiar na execução do contrato.

## Sair da lista
- Toda mensagem de marketing deve deixar claro como parar de receber, e o pedido precisa ser respeitado na hora e para sempre.
- Ao importar listas, tire quem já pediu para sair.

## Dados sensíveis
Saúde, religião, orientação sexual, dados de crianças e biometria são sensíveis: exigem cuidado maior. Imagens e informações de pacientes só com autorização específica e por escrito. Nunca use dado sensível para segmentar anúncios.

## Listas e públicos de anúncio
- Lista comprada ou contatos sem relação com o negócio: não use, nem para campanha nem para público de anúncio.
- Públicos personalizados da Meta a partir do CRM: a Meta compara os dados criptografados; mesmo assim, use só contatos que se relacionam com o negócio e diga na política de privacidade que os dados podem ser usados para anúncios.
- Mostre ao usuário só quantos contatos entram, nunca telefones ou e-mails.

## Guardar só o necessário
Colete o mínimo para o objetivo, apague o que não serve mais e restrinja quem vê os dados.
